5.3 สมบัติของการเท่ากัน

หนังสือเรียน หน้า 207–212

สมบัติของการเท่ากัน

  • สมบัติสมมาตรถ้า a = b แล้ว b = a
  • สมบัติถ่ายทอดถ้า a = b และ b = c แล้ว a = c

  • สมบัติการคูณถ้า a = b แล้ว a × c = b × c ใช้กับการหารด้วยจำนวนที่ไม่เท่ากับศูนย์ได้ด้วย

กระทรวงศึกษาธิการ. (2560). ตัวชี้วัดและสาระการเรียนรู้แกนกลาง กลุ่มสาระการเรียนรู้คณิตศาสตร์ (ฉบับปรับปรุง พ.ศ. 2560) ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช 2551. โรงพิมพ์ชุมนุมสหกรณ์การเกษตรแห่งประเทศไทย.
